
# Hangman Game - League of Legends

Esta é uma aplicação feita em React que apresenta um jogo da forca com a temática de League of Legends para que você possa adivinhar o nome do campeão. Conectado a uma API simples com banco de dados MongoDB que salva o ranking de pontuação de cada jogador.

## ⚙️ Como Rodar o Projeto Localmente

### 📋 Pré-requisitos

- Node.js >= 18
- NPM ou Yarn
- MongoDB local ou URL de conexão com cluster Atlas

### 🚀 Instalação

```
bash

# Clone o repositório
git clone https://github.com/f3gomes/hangman-game.git

# Acesse a pasta do projeto
cd hangman-game

# Instale as dependências
npm install
# ou
yarn install

# Inicie o servidor
npm run dev
# ou
yarn dev

```
